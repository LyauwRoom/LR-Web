# Lyauw Room Website

**Status:** Production

This repository contains the public Lyauw Room website.

- Live website: https://lyauw.me
- Hosting: GitHub Pages
- Production branch: `main`
- Custom domain configuration: `CNAME`

## Repository structure

- `index.html` — production landing page
- `booking-bg.png` — booking-page background
- `logo.png` — Lyauw Room logo
- `underconstruct.png` — under-construction artwork
- `CNAME` — custom-domain mapping for `lyauw.me`

## Change policy

Treat `main` as production. Review and test website changes before merging or committing them to this branch. Do not remove or change `CNAME` unless the custom-domain migration is intentional and verified.

## Related preview

CMS-driven preview work is maintained separately in [LR-Web_v1](https://github.com/LyauwRoom/LR-Web_v1).
